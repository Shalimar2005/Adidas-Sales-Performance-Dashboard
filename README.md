# Adidas Sales Performance Dashboard

## Project Overview

The **Adidas Sales Performance Dashboard** is an interactive data visualization project developed using **Microsoft Power BI**. It analyzes Adidas sales data across different products, regions, retailers, and sales methods to provide meaningful insights into sales performance and profitability.

The dashboard transforms raw sales data into clear, interactive visuals that help users understand business performance and identify trends.

## Objectives

- Analyze overall sales and operating profit.
- Track sales performance over time.
- Compare product-wise and regional sales.
- Evaluate performance across different sales methods.
- Compare retailer performance using key business metrics.
- Present business insights through an interactive dashboard.

## Dashboard Highlights

### Key Performance Indicators (KPIs)
- **Total Sales:** Overall revenue generated.
- **Operating Profit:** Total operating profit.
- **Units Sold:** Total quantity of products sold.
- **Operating Margin:** Percentage of sales retained as operating profit.

### Visual Analysis
- **Monthly Sales Trend:** Tracks sales performance over time.
- **Sales by Product:** Compares sales across Adidas product categories.
- **Sales by Region:** Analyzes performance across US regions.
- **Sales by Method:** Compares In-store, Outlet, and Online sales.
- **Retailer Performance:** Compares retailers based on sales, profit, and units sold.

## Tools and Technologies

- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation
- **DAX (Data Analysis Expressions)** — KPI and measure calculations
- **Microsoft Excel** — Source data

## Dataset

The project uses an Adidas US sales dataset containing information such as:

- Retailer and retailer ID
- Invoice date
- Region, state, and city
- Product category
- Price per unit
- Units sold
- Total sales
- Operating profit
- Operating margin
- Sales method

The dataset covers sales records from **January 2020 to December 2021**.

## Data Preparation

The data preparation process included:

1. Importing the source dataset into Power BI.
2. Removing unnecessary introductory rows.
3. Promoting the correct row to column headers.
4. Checking data types and preparing fields
